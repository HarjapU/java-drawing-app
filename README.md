# java-drawing-app

Author: Harjap Uppal

This program is a simple drawing app. It allows users to draw various shapes (Rectangle, Square, Circle) onto a canvas with customizable color and size options. 
The user can toggle between color modes (Simple/Advanced), switch between fill and outline style, and use an erase mode to remove shapes by painting over them with white.
The interface also provides functionality to clear the entire canvas, exit the program, and view help instructions.

Instructions for Use:
1. Select a shape from the dropdown.
2. Choose Simple or Advanced color mode.
3. Use dropdown to select color (Simple mode) or use sliders to adjust color (Advanced mode) and size.
4. Toggle the "Fill" button to switch between filled and outlined shapes.
5. Toggle the "Erase" button to use the eraser tool.
6. Click anywhere on the canvas to draw shapes.
7. Use "Clear" to erase all drawings, "Help" for usage instructions, and "Exit" to close the app.
